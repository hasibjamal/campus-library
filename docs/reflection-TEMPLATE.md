# Reflection — @github-handle

Copy this file to `docs/reflection-<your-handle>.md` and write it yourself (about one page).

1. **My roles** in each milestone (architect / maintainer / reviewer).
2. **A pattern I implemented**: the problem in the code before, the classes I wrote, what would break without it.
3. **A pull request I reviewed**: link, the question or suggestion I made, what changed.
4. **A pattern we rejected or removed** and whether I still agree.
5. **The live change request**: what was asked, which class we added, what we had to edit (and why).
6. **What I would design differently** next time.
